   - ✓ Supports: earthquakes, tsunamis, floods, storms, volcanoes

### 3. **REST API Endpoints**  
   - GET http://localhost/tugas/disaster-tracker/public/api/disasters
   - GET http://localhost/tugas/disaster-tracker/public/api/disasters/type/{type}
   - GET http://localhost/tugas/disaster-tracker/public/api/sync
   - GET http://localhost/tugas/disaster-tracker/public/api/stats

### 4. **Real-Time Map Interface**
   - Interactive Leaflet.js worldmap with color-coded markers
   - Live data polling every 5 minutes
   - Disaster type filters (earthquakes, tsunamis, floods, storms, volcanoes)
   - Severity-based coloring (critical/severe/moderate)
   - Manual sync button for immediate updates
   - Detailed popups with magnitude, location, depth, source

## 🔍 TROUBLESHOOTING

### Map Not Loading?
   → Check browser console (F12) for JavaScript errors
   → Verify https://tile.openstreetmap.org is accessible
   → Ensure pop-up blockers aren't interfering

### No Earthquake Data Showing?
   → Click "🔄 Sync Now" button to fetch data
   → Wait for API responses (can take 5-10 seconds)
   → Check browser DevTools Network tab for API calls

### API ERROR (HTTP 400)?
   → This is normal for some API regions/times
   → System tries multiple sources automatically
   → Data still comes from other sources that work

### Database Connection Error?
   → Ensure MySQL is running
   → Verify credentials in .env match your setup
   → Re-run: php database/setup.php
